## 📌 About the Project

This portfolio website is designed to present my personal developer profile in a clean and modern interface.

It highlights my journey as a **Developer, Innovator, and Tech Enthusiast**, along with my skills, learning experience, projects, testimonials, and contact information.

The website focuses on:

* Personal branding
* Developer profile
* Skills and expertise
* Professional networking
* Project and learning showcase
* Contact and collaboration
* Responsive user experience

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/dineshkumar-portfolio.git
```

### 2. Open the Project

```bash
cd dineshkumar-portfolio
```

### 3. Run the Website

You can open `index.html` directly in your browser or use a local development server.

For VS Code, the **Live Server** extension can be used.

## 🔐 Environment & Security

Sensitive environment files should not be committed to GitHub.

The project `.gitignore` excludes `.env` files and the Vercel directory.

> **Important:** Never commit API keys, passwords, private tokens, or other secrets to a public GitHub repository.
